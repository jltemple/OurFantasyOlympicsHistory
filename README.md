# 🏅 Fantasy Olympics Tracker

A web app to track our friend group's Fantasy Olympics results across all Olympic Games.

## Features
- Per-game team rosters and draft picks
- Daily medal progress graphs
- All-time leaderboard with "from [Game]" filter
- Medal totals, scores, and rankings

## Setup
```bash
npm install
npm run dev
```
